## 1. الواجهة العامة
```rust
pub struct Sender { pub uid: String, pub name: Option<String>, pub role: Option<String> }

pub struct ValidatedParams(BTreeMap<String, String>); // already stringified and checked

pub enum RenderError {
    BadRequest(String),   // -> 400: invalid/missing param, missing field, unsupported var value, limits
    Forbidden,            // -> 403 uniform: `require` mismatch or context doc missing
}

/// Step 1: validates client params against `template.params`.
pub fn validate_params(template:&Template, raw:&serde_json::Value) -> Result<ValidatedParams, RenderError>;
/// Step 2: the context document path (None when the template has no `context`). Renders only p./sender. refs.
pub fn context_path(template:&Template, params:&ValidatedParams, sender:&Sender) -> Result<Option<String>, RenderError>;
/// Step 3: the final notification. `doc` is the (already fetched) context document in plain JSON; `entity` is for campaigns (T9), pass None now.
pub fn render(template:&Template, params:&ValidatedParams, sender:&Sender, doc:Option<&serde_json::Value>, entity:Option<&serde_json::Value>) -> Result<Rendered, RenderError>;

pub struct Rendered {
    pub title:String, pub body:String, pub image:Option<String>,
    pub data:BTreeMap<String,String>,
    pub target:ResolvedTarget,            // Uid(String) | Role(String) | Topic(String) | Condition(String)
    pub dedupe_key:Option<String>, pub dedupe_seconds:Option<u32>,
}
```
`render` يتحقق من `context.require` أولاً (قبل أي تعويض آخر)، ولا يعتمد على المستدعي ليفعل ذلك.

## 2. القواعد (كلها إلزامية)
**المعاملات (`validate_params`):**
- `raw` يجب أن يكون كائناً (أو `null`/غائباً إذا لا توجد معاملات)؛ مفتاح غير معرَّف في `params` ⇒ `BadRequest` (لا نتجاهله بصمت)؛ معامل معرَّف غير موجود ⇒ `BadRequest`.
- `text`: نص؛ الطول بعدد **الأحرف** (`chars().count()`) ≤ `max`؛ لا أحرف تحكم عدا `\n` و`\t`؛ غير فارغ بعد القص؟ — لا تقصّ القيمة ولا تغيّرها، لكن القيمة الفارغة تماماً مرفوضة.
- `pattern`: نص يطابق regex **مثبّتة من الطرفين** (استعمل `Regex::new(&format!("^(?:{})$", pattern))` وليس البحث الجزئي)، مع `max` إن وُجد؛ وارفض الأحرف التحكمية دائماً.
- `enum`: قيمة تساوي إحدى `values` حرفياً.
- `int`: عدد JSON صحيح (أو نص رقمي صحيح) ضمن `min`/`max`؛ عدد عشري ⇒ `BadRequest`؛ يُخزَّن نصاً عشرياً قانونياً.
- حجم أي قيمة خام ≤ 4096 بايت قبل أي معالجة.
- لا تبنِ regex عند كل طلب بلا حد: ضع حدّ حجم للـpattern 200 حرف وحد حجم الـregex المترجم (`RegexBuilder::size_limit(100_000)`).

**التعويض (`render`):**
- مرور **واحد** على `segments()` يُلحق النص الحرفي والقيم المحسوبة إلى ناتج جديد. القيمة المُعوَّضة **لا تُفحص ولا تُفسَّر ثانيةً** أبداً (اختبار: `p` تساوي `"{doc.secret}"` تظهر حرفياً).
- مصادر المراجع: `p.*` من `ValidatedParams`، `sender.uid|name|role` (name/role غائبان ⇒ `BadRequest`)، `doc.<path>` و`entity.<path>` بمسار نقطي على JSON (مفتاح كائن فقط، لا فهارس مصفوفات)، `{var}` من `vars`.
- تحويل القيمة إلى نص: string كما هي؛ عدد صحيح بالعشري القانوني؛ عدد عشري ⇒ أقصر تمثيل بلا `.0` زائدة إن كان صحيحاً رياضياً (مثلاً `150000.0` بلا فلتر ⇒ `150000`)؛ bool ⇒ `true|false`؛ `null`/مفقود/كائن/مصفوفة ⇒ `BadRequest` (لا قيمة افتراضية صامتة).
- فلتر `|int`: عدد أو نص رقمي ⇒ تقريب لأقرب صحيح (`round` بعيداً عن الصفر عند المنتصف) بشرط `|x| ≤ 1e15`؛ غير ذلك ⇒ `BadRequest`. `150000.0|int` ⇒ `150000`، `"150000.6"|int` ⇒ `150001`.
- أي قيمة معوَّضة تحتوي أحرف تحكم عدا `\n` و`\t` ⇒ `BadRequest`.
- **مقاطع المسار:** في `context_path` وحده: كل قيمة معوَّضة داخل المسار ترفض `/` و`\` و`..` وأي أحرف تحكم وتكون غير فارغة (لا ترميز هنا؛ الترميز في `datasource`). النص الحرفي في القالب نفسه لا يُفحص (يُفحص في الحفظ).
- `vars`: لكل var، `from` (مرجع بلا أقواس: `doc.x|p.x|sender.x|entity.x`) يُقرأ كنص ثم يُبحث في `map` بمطابقة تامة؛ غير موجود ⇒ `BadRequest("unsupported value")` **بلا تضمين القيمة في الرسالة**. قيمة `map` تُعوَّض كقالب عادي (مراجع p/sender/doc/entity فقط، لا var؛ إن وُجدت var ⇒ `BadRequest` دفاعاً). تُحسب الـvars عند أول استعمال لها فقط (كسولاً)، وتُخزَّن لتجنب إعادة الحساب.
- **`context.require`:** لكل (حقل، قالب قيمة): القيمة المحسوبة من القالب (p/sender فقط) تُقارَن **حرفياً** (نصاً) بقيمة الحقل في `doc` محوّلة بنفس قواعد التحويل أعلاه (بلا فلتر). `doc` غائب، أو الحقل غائب، أو عدم تطابق ⇒ `RenderError::Forbidden` **موحّد** (نفس القيمة في الحالات الثلاث، دون أي نص يميّزها). المقارنة بوقت ثابت غير لازمة.
- الحدود على الناتج: `title ≤ MAX_TITLE_LENGTH`، `body ≤ MAX_BODY_LENGTH`، `image ≤ MAX_IMAGE_URL_LENGTH`، مجموع `data` (مفاتيح+قيم) ≤ `MAX_DATA_BYTES`، والطول بالأحرف/البايت كما هو معرَّف في `validation.rs` (اقرأ كيف تُحسب هناك واتبعها). `title` فارغ بعد التعويض ⇒ `BadRequest`. مفتاح محجوز في `data` (`from`، `notification`، `message_type`، `google.*`، `gcm.*`) ⇒ `BadRequest` (دفاع ثانٍ).
- الهدف: `uid` ⇒ بعد التعويض يجب أن ينجح `crate::identity::is_valid_uid`؛ `role` ⇒ `^[a-z0-9_]{1,32}$`؛ `topic`/`condition` ⇒ تُرجَع كما هي (تحققها T8 بـ`validation.rs`). فشل ⇒ `BadRequest`.
- `dedupe.key` يُعوَّض بنفس القواعد ويُرجَع مع `seconds`؛ لا تنفذ منطق dedupe هنا.
- النص العربي واليونيكود يمر دون أي تغيير (لا تطبيع، لا تحويل حالة).
- لا `unwrap`/`expect`/فهرسة قد تُسبب panic خارج الاختبارات (اقتطاع النص بالأحرف لا بالبايتات).

## 3. الاختبارات (بهذه الأسماء)
params: `param_text_counts_chars_not_bytes`، `param_text_rejects_empty_and_control_chars`، `param_pattern_is_anchored_both_ends`، `param_pattern_oversized_regex_rejected`، `param_enum_exact_match_only`، `param_int_bounds_and_rejects_float`، `param_unknown_key_rejected`، `param_missing_rejected`، `param_value_over_4096_bytes_rejected`.
render: `render_substitutes_all_sources`، `p_value_with_placeholder_is_not_reinterpreted`، `doc_value_with_placeholder_is_not_reinterpreted`، `int_filter_rounds_150000_point_0`، `int_filter_rounds_half_away_from_zero`، `int_filter_rejects_non_numeric_and_huge`، `float_without_filter_prints_integer_form`، `missing_or_null_or_object_field_is_bad_request`، `arabic_text_is_preserved_exactly`، `control_chars_in_substituted_value_rejected`، `title_empty_after_render_rejected`، `title_body_limits_enforced`، `data_total_size_limit_enforced`، `reserved_data_key_rejected`، `target_uid_must_be_valid_uid`، `target_role_charset_enforced`، `dedupe_key_rendered`.
context/require: `context_path_rejects_slash_dotdot_and_backslash_in_values`، `context_path_none_without_context`، `require_match_passes`، `require_mismatch_is_forbidden`، `require_missing_doc_is_forbidden`، `require_missing_field_is_forbidden`، `forbidden_is_uniform_for_all_three_cases` (يقارن القيم المُرجَعة وليس رسائل)، `require_runs_before_other_substitution` (doc بحقل مفقود مستعمل في body + require فاشل ⇒ Forbidden وليس BadRequest).
vars: `var_maps_doc_value`، `var_unknown_value_is_bad_request_without_echo`، `var_map_value_may_use_other_sources`، `var_referencing_var_rejected`، `var_computed_lazily_and_only_when_used`.
integration مع المثال: `watt_example_templates_render` يحمّل `policies/watt.example.json`، ويُصيّر كل قالب فيه بمعاملات ووثائق وهمية معقولة (واحد على الأقل لكل من: `admin_alert`، `order_new`، `order_status`)، ويتحقق من النواتج المتوقعة (مثلاً `150000.0` في `order_new` يُنتج `150000`). إن كانت أسماء القوالب في الملف مختلفة فاستعمل ما فيه ووثّق.
اختبار القفل: `renderer_has_no_io_dependencies` يتحقق عبر `grep` ثابت في الاختبار أو تعليق أن الملف لا يستورد `reqwest`/`sqlx`/`tokio::fs` (تحقق يدوي كافٍ إن لم يكن آلياً؛ اذكر طريقتك).

## 4. الجودة والتجارب السلبية الملزمة
`cargo fmt` (ملفاتك)، `cargo build` بلا تحذير جديد (الدوال غير المربوطة بعد: `#[allow(dead_code)]` على مستوى الوحدة `//! ` مسموح مؤقتاً في `template.rs` مع تعليق أنه حتى T8)، `cargo clippy --all-targets` صفر تحذير، `cargo test` كامل (242 + الجديد، لا ignore) ولصق `-- --list` للجديد.
ثلاث تجارب مؤقتة (أعدها وتحقق `sha256`): (أ) اجعل `render` يُعوّض في الناتج ثم يعيد المرور عليه ⇒ يجب أن يفشل `p_value_with_placeholder_is_not_reinterpreted`. (ب) اجعل مقارنة `require` تتجاوز حالة الوثيقة الغائبة (Ok) ⇒ يجب أن يفشل `require_missing_doc_is_forbidden`. (ج) اجعل الـpattern غير مثبّتة (بحث جزئي) ⇒ يجب أن يفشل `param_pattern_is_anchored_both_ends`.
