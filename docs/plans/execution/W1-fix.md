# W1-fix — إعادة محاولة تسجيل الجهاز + تسجيل عند فتح التطبيق وهو مسجّل دخول (taqati)

## المشاكل (من سجل التشغيل)
1. تسجيل الجهاز يفشل (503 أو انقطاع شبكة) ولا يُعاد حتى يسجّل المستخدم خروجاً ودخولاً.
2. عند فتح التطبيق وهو مسجّل دخول فعلاً: `register` ينطلق مرتين متزامنتين ويفشلان؛ لا يعاد التسجيل لاحقاً.
3. `unregister` عند الخروج قد يفشل فيبقى الجهاز مسجلاً باسم المستخدم السابق (إشعارات تصل لمن خرج).

## المطلوب (داخل `ApiDeviceRegistry` / `PushNotificationService` / طبقة data، بلا Firebase خارج data)
- **دمج الطلبات المتزامنة (single-flight):** نفس (token, uid) أثناء طلب جارٍ ⇒ ينتظر نفس النتيجة ولا يرسل طلباً ثانياً.
- **إعادة محاولة قصيرة:** عند 503 أو 502 أو 504 أو خطأ شبكة: حتى 3 محاولات بتأخير تصاعدي (1s، 3s، 8s) مع jitter. 4xx (غير 401/429) لا تُعاد (خطأ دائم). 429 ⇒ احترم `Retry-After` إن وُجد وإلا 30s. 401 ⇒ تجديد token مرة واحدة كما هو.
- **تخزين محلي لحالة التسجيل (`SharedPreferences` عبر واجهة domain `DeviceRegistrationStore`):**
  `{uid, fcmToken, registeredAt}` يُحفظ **فقط بعد نجاح** `register`.
  - عند فتح التطبيق/`onAuthenticated`: إن اختلف (uid, token) عن المحفوظ، أو مرّ أكثر من 7 أيام ⇒ سجّل (تجديد `last_seen` في الخادم).
  - إن فشلت كل المحاولات: لا تحفظ، وأعد المحاولة في **أول** من: عودة التطبيق للمقدمة (`resumed`)، تغيّر الاتصال إلى متصل، `onTokenRefresh`. بحد أدنى 60 ثانية بين دورات المحاولة.
- **unregister عند الخروج:** نفّذه **قبل** مسح الجلسة (كما الآن). إن فشل بعد المحاولات: احفظ `pendingUnregister {fcmToken}` محلياً وأعد المحاولة عند فتح التطبيق التالي (بـ token الجلسة الجديدة أو بعد تسجيل دخول)؛ لا تحاول بلا مستخدم (بلا طلب شبكة). ملاحظة: الخادم ينقل نفس token إلى المستخدم الجديد عند `register` فهذا يعالج الحالة الشائعة.
- لا تطبع tokens في السجل (آخر 4 أحرف كحد أقصى).

## الاختبارات
- طلبان متزامنان لنفس (token, uid) ⇒ طلب شبكة واحد.
- 503,503,200 ⇒ 3 طلبات والنتيجة نجاح والحالة محفوظة. 503×4 ⇒ فشل وغير محفوظة، ثم `resumed` يعيد المحاولة.
- 400 ⇒ لا إعادة. 401→تجديد→200 ⇒ نجاح.
- (uid, token) مطابق للمحفوظ وأقل من 7 أيام ⇒ لا طلب شبكة.
- فشل unregister ⇒ `pendingUnregister` يُحفظ ويُنفَّذ لاحقاً مرة واحدة.
- **تجربة سلبية:** عطّل الدمج مؤقتاً وأثبت فشل اختبار التزامن.
- `flutter analyze` و`flutter test` نظيفان، `dart format --line-length 160`.
