## 1. الواجهة (`datasource/mod.rs`)
```rust
pub type Doc = serde_json::Value; // a plain JSON value (strings, numbers, bools, nulls, nested objects/arrays)
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DataError { InvalidPath(String) /* caller bug -> 400-class */, Unavailable(String) /* source down or denied -> 503 */ }
#[async_trait]
pub trait DataSource: Send + Sync {
    /// `Ok(None)` means "not found". Any other failure is `Err` (callers fail closed).
    async fn get_doc(&self, path: &str) -> Result<Option<Doc>, DataError>;
    /// Returns document ids (uids) whose `field` equals `value`, at most `limit` (1..=200).
    async fn members(&self, collection: &str, field: &str, value: &str, limit: usize) -> Result<Vec<String>, DataError>;
}
```
دوال تحقق مشتركة (مع اختبارات):
- `validate_doc_path(path) -> Result<Vec<&str>, DataError>`: عدد المقاطع زوجي من 2 إلى 6؛ كل مقطع غير فارغ، ليس `.` ولا `..`، لا يحتوي `/` ولا أحرف تحكم، طوله ≤ 200. **لا تقيّد الأحرف الأخرى** (معرّفات Auth0 مثل `auth0|123` مشروعة)؛ بدلاً من ذلك يُرمَّز كل مقطع عند الإرسال (percent-encoding للبايتات غير `[A-Za-z0-9_.~-]`).
- `validate_collection(c)`: `^[A-Za-z0-9_-]{1,100}$`. `validate_field(f)`: مقاطع `[A-Za-z0-9_]+` تفصلها نقطة (حتى 5). `value` طوله ≤ 200 بلا أحرف تحكم. `limit` ضمن 1..=200 وإلا `InvalidPath`.
- `pub(crate) fn percent_encode(segment:&str)->String`.

## 2. Firestore (`datasource/firestore.rs`)
- `trait AccessTokenProvider { async fn token(&self) -> Result<String,String> }` مع تنفيذ حقيقي يغلّف `AuthMap` لتطبيق معيّن بنطاق `https://www.googleapis.com/auth/datastore` (نفس طريقة `FirestoreHttp`)، وتنفيذ ثابت للاختبارات.
- `FirestoreDataSource::new(client, tokens: Arc<dyn AccessTokenProvider>, project_id)` و`with_base_url(url)` للاختبارات (الافتراضي `https://firestore.googleapis.com`).
- `get_doc`: `GET {base}/v1/projects/{project}/databases/(default)/documents/{encoded path}`. 404 ⇒ `Ok(None)`. 401/403 ⇒ `Unavailable` برسالة الإرشاد نفسها الموجودة في `FirestoreHttp` (اطلب `roles/datastore.viewer`). غير ذلك غير ناجح ⇒ `Unavailable("Firestore returned HTTP <code>")`. مهلة 10ث. جسم الرد ≤ 1MB (اقرأه بـ`bytes()` وتحقق من الطول)، وأكبر ⇒ `Unavailable`.
- `members`: `POST {base}/v1/projects/{project}/databases/(default)/documents:runQuery` بجسم `structuredQuery` (`from: [{collectionId}]`, `where.fieldFilter{field.fieldPath, op:EQUAL, value:{stringValue}}`, `select.fields:[{fieldPath:"__name__"}]`, `limit`). الرد مصفوفة؛ استخرج آخر مقطع من `document.name` لكل عنصر فيه `document` (العناصر بلا `document` تُهمل). **القيمة تُرسل كنص فقط** (إذا كان الحقل رقمياً فهذا مقيَّد حالياً؛ وثّق ذلك).
- `pub fn from_firestore_document(doc:&Value)->Doc`: يحوّل `fields` المنمّطة إلى JSON عادي: `stringValue`, `integerValue` (نص ⇒ رقم i64، وإن فشل فنص), `doubleValue`, `booleanValue`, `nullValue`⇒null, `timestampValue`⇒نص, `referenceValue`⇒نص, `bytesValue`⇒نص, `geoPointValue`⇒`{latitude,longitude}`, `mapValue.fields` و`arrayValue.values` (فارغة مقبولة) بشكل متكرر بعمق أقصى 8 (الأعمق ⇒ `Unavailable`، أي لا قطع صامت). نوع مجهول ⇒ `Unavailable("unsupported Firestore value type")`.
  وهذا التحويل هو ما تقرؤه القوالب لاحقاً (`{doc.total}`)، فاختبره جيداً.

## 3. HTTP resolver (`datasource/http.rs`)
`HttpDataSource::new(client, cfg: HttpSourceConfig{base_url, secret_env, timeout_ms}, env: Arc<dyn EnvSource>)`.
**العقد (يعتمده هذا الأمر بدل جدول 3.4 في الخطة، وحدّث الخطة في commit التوثيق):**
- `GET {base}/doc?path=<percent-encoded full path>` ⇒ `200` + كائن JSON، أو `404`.
- `GET {base}/members?collection=<c>&field=<f>&value=<v>&limit=<n>` ⇒ `200 {"uids":["...", ...]}`. (إضافة `collection` عن الجدول القديم.)
- **التوقيع (بلا Bearer، فالسر لا يُرسَل أبداً):** الترويسات `X-FCM-Timestamp` (ثواني UNIX) و`X-FCM-Signature` = hex صغير لـ `HMAC-SHA256(secret, canonical)` حيث
  `canonical = "GET" + "\n" + <URL path as sent, e.g. /internal/fcm/doc> + "\n" + <raw query string as sent> + "\n" + <timestamp>`.
  ترتيب معاملات الاستعلام ثابت كما في أعلاه، والترميز percent-encoding بحروف hex كبيرة، ويُوقَّع النص **كما أُرسل**.
- **متجه اختبار إلزامي** (يجب أن يطابقه Rust ومثال Python حرفياً): secret = `test-secret-test-secret-test-secret-00`، path = `/internal/fcm/doc`، query = `path=store_orders%2Fabc123`، timestamp = `1700000000` ⇒ احسب التوقيع في Rust ثم ثبّت القيمة الناتجة كثابت في الاختبار وفي `examples/README.md` ومثال Python.
- السر: `env.get(secret_env)`؛ غير موجود أو أقصر من 32 بايت ⇒ `Unavailable("data source secret is not configured")` (سجّل اسم المتغير فقط). لا تسجّل السر ولا التوقيع ولا الجسم.
- عميل `reqwest` مخصص: `redirect::Policy::none()`، مهلة `timeout_ms`، جسم ≤ 1MB. رفض `base_url` غير `https://` إلا `http://localhost` و`http://127.0.0.1` (تحقق وقت التشغيل أيضاً).
- ردود: `200` يجب أن يكون كائن JSON (غير ذلك ⇒ `Unavailable("resolver returned an invalid document")`)؛ `404` ⇒ `Ok(None)` (للـ doc) أو `Unavailable` (لـ members: 404 لا يعني فراغاً)؛ أي شيء آخر ⇒ `Unavailable("resolver returned HTTP <code>")`. `uids` عناصر نصية 1..128 حرفاً بلا أحرف تحكم، وأكثر من `limit` ⇒ اقتطع واكتب `tracing::warn!`.

## 4. مثال الباك إند (`examples/resolver_fastapi.py` + `examples/README.md`)
- ملف Python واحد (~80 سطراً)، تعليقاته بالإنجليزية. يستورد FastAPI **عند الخدمة فقط** (داخل `if __name__ == "__main__"` أو دالة `create_app()`) حتى يعمل `--selftest` بمكتبة Python القياسية وحدها.
- يقدّم `GET /internal/fcm/doc` و`GET /internal/fcm/members` على قاعدة بيانات تجريبية (dict) مع تعليق واضح أين تُستبدل بقاعدتهم الحقيقية. يتحقق: وجود الترويسات، انحراف الوقت ≤ 60ث، ثم مقارنة التوقيع بـ`hmac.compare_digest` على `canonical` المبني من `request.url.path` و`request.url.query` **الخام**، وإلا `401`. السر من متغير بيئة `FCM_RESOLVER_SECRET`.
- `python3 examples/resolver_fastapi.py --selftest` يحسب متجه الاختبار بالمكتبة القياسية ويطبع `OK` أو يخرج بكود 1.
- `README.md` قصير: العقد، متجه الاختبار، تشغيل المثال، وتنبيه: يجب أن يحافظ الـ reverse proxy على المسار كما أُرسل (لا يعيد كتابة prefix) وإلا يفشل التوقيع.

## 5. السجل (`datasource/registry.rs`)
`DataSourceRegistry::new(config: Arc<ConfigStore>, project_map: ProjectIdMap, auth_map: AuthMap, client: reqwest::Client, env: Arc<dyn EnvSource>)` و`source_for(app) -> Result<Arc<dyn DataSource>, DataError>`:
- حسب `config.data_source`: `firestore` ⇒ يحتاج `project_id` (غير موجود ⇒ `Unavailable("app has no loaded credentials")`)؛ `http` ⇒ `HttpDataSource`؛ `none` ⇒ مصدر يرجع `Unavailable("this app has no data source")` لكل استدعاء (دفاع إضافي، فالتحقق يمنع ذلك أصلاً).
- مخبأ لكل `(app, config.version)` ويُعاد بناؤه عند تغيّر النسخة. تطبيق بلا إعداد لكن له credentials ⇒ Firestore الافتراضي مع `warn` مرة واحدة. تطبيق مجهول ⇒ `Unavailable("unknown app")`.
- لا تضفه إلى `AppState`.

## 6. الاختبارات المطلوبة (بهذه الأسماء)
- paths: `doc_path_accepts_pairs_and_special_ids` (مثل `users/auth0|123`)، `doc_path_rejects_dot_segments_slashes_and_odd_lengths`، `doc_path_rejects_control_chars_and_long_segments`، `collection_and_field_validation`، `percent_encode_segment`.
- firestore: `firestore_value_conversion_all_types`، `firestore_conversion_rejects_unknown_type`، `firestore_conversion_depth_limit_is_an_error`، `firestore_get_doc_found`، `firestore_get_doc_not_found_is_none`، `firestore_get_doc_403_is_unavailable_with_guidance`، `firestore_get_doc_500_is_unavailable`، `firestore_response_over_1mb_is_unavailable`، `firestore_members_extracts_ids_and_skips_empty_results`، `firestore_members_sends_expected_query`.
- http: `signature_matches_known_test_vector`، `http_get_doc_signs_request_and_parses_object`، `http_get_doc_404_is_none`، `http_members_404_is_unavailable`، `http_non_object_doc_is_unavailable`، `http_members_truncates_to_limit`، `http_secret_missing_is_unavailable`، `http_short_secret_is_unavailable`، `http_refuses_non_https_non_localhost_base_url`، `http_does_not_follow_redirects`، `http_timeout_is_unavailable`، `http_secret_never_appears_in_request`.
- registry: `registry_builds_source_per_config`، `registry_rebuilds_when_config_version_changes`، `registry_caches_source_between_calls`، `registry_defaults_to_firestore_without_config`، `registry_firestore_without_credentials_is_unavailable`، `registry_none_source_always_unavailable`، `registry_unknown_app_is_unavailable`.
**بلا اعتماديات اختبار جديدة:** اكتب خادم HTTP/1.1 مصغّراً في الاختبارات بـ`tokio::net::TcpListener` (يقرأ سطر الطلب والترويسات ويرد برد جاهز، ويسجّل الطلب الخام لفحصه). اختبار `http_secret_never_appears_in_request` يبحث في الطلب الخام عن قيمة السر ويجب ألا يجدها. اختبار التوقيع في الاختبارات يعيد حساب HMAC **باستقلال** عن كود الإنتاج (نفس المواصفة المكتوبة أعلاه، لا استدعاء دالة الإنتاج).
